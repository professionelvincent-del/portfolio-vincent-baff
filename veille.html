Nom : Vincent Baff

Formation : BTS SIO

1. Qu'est-ce qu'une veille technologique ?

Une veille technologique consiste à rechercher régulièrement des informations sur les nouvelles technologies et l'informatique.

2. Pourquoi faire une veille ?

Elle permet de rester informé des nouveautés, d'apprendre à utiliser de nouveaux outils et de connaître les risques informatiques.

3. Comment faire une veille ?

  • Choisir un sujet.
  • Rechercher des informations sur Internet.
  • Consulter des sites régulièrement.
  • Garder les informations importantes.

4. Les différents types de veille

  • Veille technologique : suivre les nouveautés informatiques.
  • Veille juridique : suivre les nouvelles lois.
  • Veille concurrentielle : observer les autres entreprises.
  • Veille commerciale : suivre les nouveaux produits.
  • Veille informatique : suivre les problèmes de sécurité.

5. Mon sujet de veille : le phishing

J'ai choisi le phishing, aussi appelé hameçonnage. C'est une arnaque qui utilise de faux mails ou de faux SMS pour essayer de voler des informations personnelles.

6. Pourquoi ai-je choisi ce sujet ?

J'ai choisi ce sujet car le phishing est fréquent. Il peut toucher les particuliers et les entreprises. Il est important de savoir reconnaître les messages dangereux.

7. Les outils pour suivre mon sujet

  • Google : rechercher des informations récentes.
  • Google Alertes : recevoir des alertes sur le phishing.
  • Cybermalveillance : trouver des conseils pour éviter les arnaques.
